Screen E.3

User Account Registration Screen

Gathers candidate profile details, validates password complexity, and triggers verification.

  • [1] Back Navigation: Returns to previous entry screen.
  • [2] Application Brand: Visual identifier.
  • [3] Full Name Field: Text input for examinee legal name.
  • [4] Email Address: Email for login and Supabase account verification.
  • [5, 7] Password / Confirm Inputs: Masked fields with active focus styling.
  • [6, 8] Eye Toggles: Switches masking between plain text and dots.
  • [9, 10, 11] Password Rules: Live feedback for length (≥6), numbers (0–9), and matching.
  • [12, 13] Terms Checkbox & Link: User agreement and link to Terms modal.
  • [14] Sign Up CTA: Submits registration and sends confirmation email.
  • [15] Google SSO: One-tap OAuth login.
  • [16] Sign In Route: Routes existing users to login.

Main Examinee Dashboard

Central study cockpit offering readiness percentages, daily goal progress, and topic breakdowns.

  • [1] Examinee Header: Shows active avatar and civil service track.
  • [2] Overflow Action Menu: Access to reset data and logout.
  • [3] Level Switcher: Instant toggle between Professional and Sub-Professional.

  • [10, 11] Subject Mastery: Expandable list showing readiness across subjects.

Screen E.9

Interactive Exam Question Interface

Core test-taking viewport supporting multiple choice selection, countdown timing, and text-to-speech audio.

  • [1] Quit Exam (X): Aborts test session with confirm prompt.
  • [2] Subject Category Tag: Identifies the active test section.
  • [3] Question Grid Modal: Opens full question matrix.
  • [4] Question Tracker: Displays index and progress.
  • [5] Countdown Timer: Real-time clock with low-time alert.
  • [6] Question Stem: Formatted problem statement or passage.
  • [7] Audio Reader Button: Text-to-Speech narration.
  • [8–11] Option Radios (A, B, C, D): Tap targets for selecting choices.
  • [12] Instant Explanation: Live answer key and rationale in Review Mode.
  • [13] Previous Button: Navigates to preceding question.
  • [14] Next / Submit Button: Advances or opens final submission dialog.

Screen E.13

Exam Diagnostic Result Screen

Presents overall score, official pass/fail status, and diagnostic sub-topic breakdown.

  • [1] Done Navigation: Direct exit to Home tab.
  • [2] Result Banner: Percentage score and pass/fail indicator.
  • [3, 4] Accuracy Metrics: Count of correct and wrong responses.
  • [5] Time Elapsed: Total duration of test attempt.
  • [6] CSC Benchmark: 80% passing grade requirement.
  • [7] Sub-Topic Analysis: Itemized breakdown highlighting strengths and weaknesses.
  • [8] Review Answers CTA: Directs candidate to the rationales screen.
  • [9] Retake Exam CTA: Starts a new practice session.
  • [10] Dashboard Route: Returns to main screen.
